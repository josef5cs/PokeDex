# PokeDex
1- Pokedex de execução simples, basta abrir o Link que se encontra nas descrições desse repositório ou baixar o arquivo e executar o index.html.
2- Há duas formas de usar a Pokedex, através da busca pelo nome do Pokemon ou pelo número.
3- A pokedex é responsiva tanto pra navegadores de qualquer tamanho quanto para Mobile.
